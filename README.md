# ECG Lab

Application for ECG signal visualization, denoising, and arrhythmia classification with vital signs monitoring.

## Demo

https://github.com/user-attachments/assets/b5c7bf75-204a-4848-8aa2-ce8fa1304964 

## Features

- **ECG Signal Processing**
  - Advanced denoising
  - Multi-lead ECG visualization

https://github.com/user-attachments/assets/f07eaf2a-61e4-4b82-b290-75cd9dd4ed3b 

  
  
- **Arrhythmia Detection**
  - Automatic classification of cardiac rhythms
    
  ![Image](https://github.com/user-attachments/assets/d33ea4ae-9c64-4616-932a-4696ec0836ee)
  - Visual and audible alarms for abnormalities
  - Heart rate calculation
